# Имя не подтягивается в сессию при обычном логине (только id из /users/me)

**Date:** 2026-07-03 18:17
**Files:** src/app/api/auth/login/route.ts, src/app/api/auth/login/route.test.ts
**Severity:** medium

## Problem

После успешного входа приветствие показывало пустое имя («Доброе утро, »).
Сразу после регистрации имя отображалось, а при последующих логинах пропадало.

## Root Cause

`login/route.ts` — единственный из auth-роутов — читал `first_name` из ответа
Directus `/users/me`, вызванного с **токеном самого пользователя**. Роль «Чтец»
в Directus 11 работает через app-access policy c фильтром `$CURRENT_USER`, которая
на практике отдаёт через `/users/me` только поле `id` (первичный ключ), несмотря на
то что в permissions роли перечислены `first_name/last_name/...`. Воспроизведено
запросом `/users/me` под реальным пользовательским токеном → `{"data":{"id":"…"}}`.

`activate/route.ts` и `register/route.ts` этой ловушки избегали: они читают профиль
через **admin-клиент** по `directus_id`. Поэтому имя было видно только сразу после
создания аккаунта, а на логине терялось.

## Solution

В `login/route.ts` после получения `directusId` из `/users/me` (используется только
для резолва id) читаем `first_name/last_name/email` через `getDirectusAdminClient()`
+ `readUsers(filter id _eq directusId)` — тот же паттерн, что в activate/register.
Ошибку admin-чтения не роняем в 500: логин проходит, имя останется пустым и догрузится
позже. Добавлены `[FIX]`-логи и unit-тесты (`route.test.ts`), фиксирующие, что
`first_name` берётся из admin-клиента даже когда `/users/me` вернул только `id`.

## Prevention

- Никогда не полагаться на `/users/me` под пользовательским токеном для чтения полей
  профиля: в Directus 11 field-level доступ определяется policy роли и легко отдаёт
  только `id`. Для серверных нужд читать профиль admin-клиентом по id.
- Держать auth-роуты согласованными: если два из трёх делают admin-read профиля —
  третий не должен молча отличаться.
- Тест-инвариант: сессия должна получать имя даже при «худом» `/users/me` (только id).
