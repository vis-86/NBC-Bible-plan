# BottomSheet: ESLint react-hooks/set-state-in-effect

**Date:** 2026-04-22 23:24 UTC
**Files:** `src/shared/components/ui/BottomSheet.tsx`
**Severity:** low

## Problem

`yarn lint` падал с `react-hooks/set-state-in-effect`: в `useEffect` при `!isOpen` вызывались `setDragY` / `setIsDragging` — синхронный setState в эффекте.

## Root Cause

Сброс drag-состояния при закрытии шита делался эффектом по `isOpen`. Правило ESLint (React Compiler–friendly) запрещает такой паттерн из‑за каскадных ререндеров.

## Solution

- Вынесен **`BottomSheetOpenContent`**: монтируется только когда `BottomSheet` ренерится с `isOpen === true`; при закрытии весь inner размонтируется — `dragY` / `isDragging` / ref обнуляются без эффекта.
- Обёртка **`BottomSheet`** без своих хуков: `if (!isOpen) return null; return <BottomSheetOpenContent ... />`.
- Логи **`[FIX]`** при `DEBUG_FIX=1` или `NODE_ENV=development`: монтирование inner, успешный dismiss по drag.

## Prevention

- Для «сброса UI при закрытии модалки» предпочитать размонтирование дочернего дерева или ключи, а не `useEffect` + `setState` по флагу открытия.
- После правок в клиентских компонентах с хуками — `yarn lint` на файл.
