### Project-specific review checklist (derived from recurring bug classes)

**Rule**: Apply these questions to every reviewed diff in their trigger areas:
- For every `cache.match(x)` / IDB `get(key)`: "under which exact key was this written, by whom?" — key literals must be shared exported constants; cache-busting query params break exact matches.
- For every `await fetch(...)` preceding a fallback: "what happens if this promise stays pending for 2 minutes?" — real offline hangs requests, it doesn't reject them.
- For every `return promise` inside a catch/fallback branch: "under what conditions does this promise never resolve?" — waiting is not error handling when `navigator.onLine === false`.
- For carousels/lists >50 items with motion-values: item component memoized? handlers stable across scroll ticks (ref-pattern)? `useTransform` chain single-level? pulse/snap ≤10% amplitude without overshoot easing?
- For state added to a shared/generic primitive: grep all importers — does every consumer expect this policy (a non-network consumer of a network breaker is an outage)?
