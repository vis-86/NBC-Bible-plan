# Миграция: Добавление поддержки отметки глав не по порядку

## Описание изменений

Добавлена возможность отмечать главы в плане чтения в любом порядке, без необходимости читать их последовательно.

## Изменения в базе данных

Необходимо добавить новое поле `completed_items` в таблицу `reading` в Directus.

### Инструкция по добавлению поля в Directus

1. Откройте панель администратора Directus
2. Перейдите в Settings → Data Model
3. Найдите коллекцию `reading`
4. Нажмите кнопку "Create Field"
5. Заполните параметры поля:
   - **Field Name**: `completed_items`
   - **Field Type**: JSON
   - **Allow NULL**: Yes (включить)
   - **Default Value**: null

6. Сохраните изменения

### SQL миграция (альтернативный способ)

Если у вас есть прямой доступ к базе данных SQLite, вы можете выполнить следующий SQL запрос:

```sql
ALTER TABLE reading ADD COLUMN completed_items TEXT;
```

Примечание: В SQLite JSON хранится как TEXT.

## Что изменилось в коде

1. **TypeScript схема** (`src/lib/directus-schema.ts`):
   - Добавлено поле `completed_items?: number[] | null` в интерфейс `reading`

2. **Логика отметки глав** (`src/features/plan/contexts/PlanContext.tsx`):
   - Функция `toggleItem` теперь отслеживает конкретные прочитанные главы
   - Пользователь может отмечать главы в любом порядке
   - Поле `count` сохраняется для обратной совместимости

3. **GraphQL мутация** (`src/shared/services/api/graphql.ts`):
   - Добавлен параметр `completedItems` в мутацию `updateProgress`

4. **API обработчик** (`src/app/api/graphql/route.ts`):
   - Обновлена логика сохранения прогресса с поддержкой `completed_items`

5. **Загрузка данных** (`src/features/plan/contexts/PlanContext.tsx`):
   - Функция `fetchPlan` корректно обрабатывает поле `completed_items`
   - Сохранена обратная совместимость со старыми записями

## Обратная совместимость

Система полностью обратно совместима:
- Старые записи с только полем `count` будут работать как прежде
- Новые записи используют `completed_items` для хранения конкретных прочитанных глав
- Поле `count` продолжает сохраняться для совместимости с другими системами (например, Python-ботом)

## Тестирование

После добавления поля в базу данных:
1. Откройте приложение
2. Выберите любой день в плане чтения
3. Попробуйте отметить главу не по порядку (например, отметьте главу 3, не читая главы 1 и 2)
4. Убедитесь, что глава отмечается корректно
5. Перезагрузите страницу и проверьте, что отметка сохранилась

## Откат изменений

Если потребуется откатить изменения:
1. Поле `completed_items` можно оставить в базе (не будет использоваться)
2. Вернуться к предыдущей версии кода через git
